# App env

- `NEXT_PUBLIC_APP_URL` — public app URL (`https://sorobill-app.vercel.app` in production)
- `NEXT_PUBLIC_API_URL` — backend base (default `http://localhost:3001/api/v1`)
- `NEXT_PUBLIC_USE_MOCK` — `true` forces mock plan data
- `NEXT_PUBLIC_SUBSCRIPTION_CONTRACT_ID` — Sorobill contract

Live demo: [https://sorobill-app.vercel.app](https://sorobill-app.vercel.app)
